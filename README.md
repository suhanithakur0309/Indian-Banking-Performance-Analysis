# Indian Banking Sector: Performance, Profitability & Risk Analysis

## Overview

This project analyses the financial performance and health of Indian banks using RBI banking data across multiple years.

The aim was to understand banking performance through **deposits, advances, profitability, asset quality and capital adequacy**, rather than focusing on a single indicator.

## Objectives

* Compare the performance of Indian banks
* Analyse deposits and advances over time
* Evaluate profitability using Net Profit and ROA
* Analyse asset quality through NPA
* Compare capital adequacy using CRAR
* Identify differences in bank performance and risk

## Tools Used

* **Power BI** — Dashboard & visualisation
* **Power Query** — Data cleaning and transformation
* **DAX** — Measures and KPIs
* **RBI Banking Data** — Data source

## Key Insight

The project shows that **bank performance cannot be judged by profitability alone**. Combining profitability with asset quality, lending activity and capital adequacy provides a more complete picture of financial health.
